# certificados/

Pon aquí las imágenes (PNG/JPG) de tus CERTIFICADOS.
- El nombre del archivo = título en el CV. Ej: `AWS_Cloud_Fundamentos.png` → "AWS Cloud Fundamentos".
- Ordena con prefijos: `01_`, `02_`, `03_`…
- Un certificado por imagen. Nítida, derecha y completa (ancho ≥ 1000 px).
- Borra las imágenes de EJEMPLO antes de generar.

Ver el formato completo en `../README.md`.
