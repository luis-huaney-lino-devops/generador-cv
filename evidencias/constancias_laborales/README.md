# constancias_laborales/

Pon aquí las imágenes (PNG/JPG) de tus CONSTANCIAS DE TRABAJO / cartas de referencia.
Mismas reglas que `certificados/` (nombre = título, prefijos de orden, una por imagen).

Ojo con datos sensibles (nombres, DNI, firmas): usa la versión COMPLETO solo con
quien te la pida. Ver `../README.md`.
