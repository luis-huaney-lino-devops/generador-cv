# /cv — CVs generados (salidas)

Aquí quedan los `.docx` que produce el motor. **No los edites a mano**: si algo
está mal, corrige el contenido en `/generador/contenido_*.js` y regenera. Editar
el docx directamente se pierde en la siguiente generación.

## Subcarpetas
- `es/` → versiones en español.
- `en/` → versiones en inglés.

## Convención de nombres (no cambiar)
```
CV_Luis_Huaney_ES.docx            → español, SIMPLE (solo texto)
CV_Luis_Huaney_ES_COMPLETO.docx   → español, COMPLETO (texto + anexos con imágenes)
CV_Luis_Huaney_EN.docx            → inglés,  SIMPLE
CV_Luis_Huaney_EN_COMPLETO.docx   → inglés,  COMPLETO
```

## ¿Cuál enviar?
- **SIMPLE** → para postular en portales / sistemas ATS y envíos por correo.
  Es liviano, sin imágenes, óptimo para que lo lean los filtros automáticos.
- **COMPLETO** → solo cuando el empleador pide **evidencias adjuntas**
  (certificados, constancias). Lleva una sección final de ANEXOS con las imágenes.

## Formato de salida
- A4, fuente serif (Times New Roman), 1–3 páginas según versión.
- Si quieres PDF, abre el docx y "Guardar como PDF" (o exporta con LibreOffice).
