# /ejemplos — Casos resueltos de adaptación

Ejemplos de cómo el agente transforma el CV para un puesto concreto. Sirven de
plantilla mental: muestran qué titular usar, qué bullets elegir y cómo reordenar
las habilidades.

## Contenido
- `ejemplo_frontend_senior_react.md` → adaptación para "Frontend Senior React".

## Formato de un ejemplo (si agregas más)
Sigue esta estructura para que sea útil a la IA:
1. **Titular** propuesto para el rol.
2. **Perfil** ajustado (2–3 frases, sin inventar).
3. **Experiencia**: bullets seleccionados por empleo (área del rol primero).
4. **Habilidades**: orden de categorías.
5. **Comando** para generar.
6. **Nota para Luis**: qué verificar antes de enviar.

## Nombre de archivo sugerido
`ejemplo_<rol>_<stack>.md` → ej. `ejemplo_backend_dotnet.md`, `ejemplo_devops_aws.md`.
